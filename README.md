# 수인 인생 시뮬레이션 게임 · BEAST LIFE

현대 수인 사회에서 0세부터 인생의 마지막까지, 학교·직장·관계·가족·경제 속 선택으로 삶을 만들어가는 한국어 웹게임입니다.

**[공개 게임 플레이](https://beast-life-minseok-20261107.kimms01kr.chatgpt.site)**

동물의 특징을 가진 **수인의 사회생활과 인생 선택**이 중심입니다. 종족의 신체·감각·식단·생활 환경 차이를 반영하되, 종족에 따라 지능·도덕성·인격의 우열을 정하지 않습니다.

이 저장소는 지금까지의 프로젝트 내용을 정리한 **문서 저장소**입니다. 게임 소스 코드와 종족 이미지 원본은 아직 포함하지 않습니다.

## 현재 플레이 흐름

1. 시작 화면에서 **시작하기**를 누릅니다. 저장된 인생이 있다면 **이어하기**가 표시됩니다.
2. 종족·이름·성별·가족·출생 환경이 무작위로 정해지며 0세, 개인 현금 0원으로 시작합니다.
3. **시간 보내기**를 누르면 달력 기준 1년의 게이지가 조금씩 찹니다. 별도의 1일·1주·1개월·1년 선택 버튼은 없습니다.
4. 선택이 필요한 사건이 발생하면 시간이 멈추고 팝업이 자동으로 열립니다.
5. 소요 시간·비용·기본 상태 변화량과 조건부 효과를 확인하고 선택합니다. 자동 진행 중이었다면 선택 후 남은 기간이 이어집니다.
6. 한 해가 끝나면 멈춥니다. 다음 해는 같은 시간 보내기 버튼으로 시작하며 중간 일시정지도 가능합니다.
7. 인생의 기록을 검색하고, 저장·내보내기·가져오기를 이용합니다. 새 인생을 시작하면 이전 인생은 보관함에 남습니다.

## 핵심 구현

- 포유류·조류·파충류·양서류 기반 **132종 수인 프로필**과 개별 아이콘
- 종족 특성과 나이·생활 조건에 따른 사건 및 선택
- 학교·직장·주거·관계 등 12개 사회생활 주제의 대응과 후속 사건
- 선택 효과, 시간 경과, 일부 확률 결과가 함께 반영되는 상태 시스템
- 영유아·미성년·성인을 구분한 개인 현금과 보호자 경제
- 건강·법률·가족·교육·직업·주거·경제 정보
- 브라우저 로컬 저장, 구버전 저장 호환, 인생 보관 및 JSON 백업
- 모바일 정보 탭, 상단 고정 시간 게이지, 밝은/어두운 테마

## 규모와 해석

현재 콘텐츠는 공통 사건 156개와 종족별 파생 항목 5,808개, 총 **5,964개 데이터 항목**으로 구성됩니다. 공통 구조를 종족에 맞게 변형한 항목과 후속 사건을 포함한 수이며, 모두 별도로 집필된 5,964개의 이야기를 뜻하지 않습니다.

종족의 수명·성숙 연령·능력치와 경제 금액·제도는 게임용 모델입니다. 생물학적 사실과 가상 설정을 함께 사용하며 과학적으로 완전히 검증된 데이터베이스를 표방하지 않습니다.

## 기술과 저장

React 19 · TypeScript · Vite · Tailwind CSS · Zustand · IndexedDB · Zod · Vitest를 사용합니다. 게임 실행에 외부 AI API나 별도의 게임 백엔드는 필요하지 않습니다.

진행 기록은 **사용 중인 브라우저에 저장**됩니다. 기기 간 클라우드 동기화와 여러 탭의 동시 저장 충돌 감지는 구현되지 않았습니다. 중요한 기록은 게임 내 JSON 내보내기로 보관할 수 있습니다.
