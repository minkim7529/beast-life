# 기술 구조와 검증 결과

## 기술 구성

- 화면: React 19, TypeScript, Vite, Tailwind CSS
- 상태 관리: Zustand
- 저장: IndexedDB, JSON 내보내기/가져오기
- 저장 검증: Zod
- 테스트: Vitest, fake-indexeddb
- 배포: 정적 웹사이트 호스팅

게임 로직은 브라우저에서 실행됩니다. 사용자 계정 서버나 외부 AI API가 없어도 플레이할 수 있습니다.

## 원본 코드 구조

아래 경로는 별도 보관된 게임 원본 프로젝트의 구조입니다. 현재 문서 저장소에는 소스 파일이 포함되지 않습니다.

```text
src/app/App.tsx                  화면과 정보 패널 연결
src/components/                 시작 화면, 선택창, 상태, 연간 게이지
src/stores/gameStore.ts          명령 처리, 저장 전환 잠금, 저장 순서 관리
src/engine/game.ts               시간 진행, 사건 해결, 활동 완료, 사망
src/engine/random.ts             시드 기반 난수
src/data/                       종족, 사건, 사회 콘텐츠, 각종 설정
src/systems/                    생물학, 가족, 사회, 건강·법률, 저장
src/types/                      게임 및 저장 데이터 스키마
src/tests/                      단위·회귀·통합·시뮬레이션 테스트
public/assets/species/          종족별 PNG
```

## 기능 연결

사용자 입력 → Zustand 명령 → 현재 Game 복제 → 엔진/분야별 시스템 처리 → 저장 데이터 검증 → 화면 갱신 및 IndexedDB 저장의 순서로 연결합니다.

시간 진행에는 일간 건강·생물학·법률, 월간 경제·가족, 생일 성장, 활동 완료, 사건 추첨/예약이 연동됩니다. 사망 또는 대기 사건이 생기면 진행을 멈춥니다.

시드 난수 상태, 현재 날짜, 대기 사건, 진행 중 활동, 남은 기간을 보존합니다. 연간 진행을 작은 구간으로 나누어도 한꺼번에 진행한 경우와 같은 사건 결과 및 난수 상태를 유지하도록 검증했습니다.

기존 저장은 버전별 이전과 종족 개편 이전을 거쳐 읽습니다. 새로운 게임을 열거나 저장을 가져오는 동안의 중복 입력은 같은 탭 안에서 잠급니다.

## 원본 프로젝트 실행 명령

소스 코드와 package.json이 있는 원본 프로젝트에서 실행하는 명령입니다. 이 문서 저장소만 복제해서는 실행할 수 없습니다.

```sh
npm ci
npm run dev -- --port 5173 --strictPort
npm test
npm run build
npm run preview -- --port 4173
```

## 확인된 테스트 기록

- 연간 자동 진행 변경: 18개 테스트 파일, 147개 테스트 통과. 전체 1,000회 생애 시뮬레이션 포함.
- 선택 효과 안내 변경: 시뮬레이션을 제외한 기존 146개 테스트와 신규 안내 테스트 2개 통과.
- 최신 선택 안내 변경 후 TypeScript 및 Vite production build 통과.
- 이전 종족·경제 검증에서 132종 × 2개 정책의 264회 비교, 저장 왕복과 이전 자산 보존 등을 확인.
- 신규 안내 테스트는 미리보기가 저장/난수 상태를 변경하지 않는지, 긴급 선택과 완료 효과를 구분하는지 확인.

위 수치는 해당 변경 당시 실행한 결과입니다. 신규 테스트를 포함한 최신 전체 테스트를 한 번에 모두 재실행했다고 주장하지 않습니다. 이번 문서 작성일에 테스트를 새로 실행하지 않았습니다.

## 브라우저에서 직접 확인한 흐름

시작하기와 이어하기, 무작위 프로필 아이콘, 시간 중단과 사건 선택, 팝업 닫기·재열기, 저장·새로고침, JSON 내보내기·가져오기, 새 인생과 이전 인생 보관을 확인했습니다.

연간 진행에서는 게이지 44%에 사건 팝업이 자동으로 열리고, 선택 후 재개되며, 46%에서 일시정지한 진행이 새로고침 후 복원되는 것을 확인했습니다. 선택 안내에서는 기본 상태 변화량과 즉시 피로 변화가 함께 표시되는 것을 확인했습니다.

일부 이전 화면은 390px 모바일 너비에서도 검사했습니다. 다만 최신 게이지의 뷰포트 변경이 적용되지 않은 검사도 있어 최신 모든 화면의 모바일 검증을 완료한 것으로 보지 않습니다. 실제 iOS/Android 기기 및 Safari는 미검증입니다.
