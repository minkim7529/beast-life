# 알려진 제한과 다음 개선 과제

아래는 현재 한계와 제안이며, 완료된 기능이나 확정 개발 일정이 아닙니다.

## 저장과 안정성

- 같은 브라우저의 여러 탭은 현재 저장을 공유합니다. 탭 간 충돌 감지가 없어 마지막 저장이 남을 수 있습니다.
- 계정 기반 저장, 기기 간 클라우드 동기화는 미구현입니다.
- 브라우저 데이터 삭제 시 로컬 기록을 잃을 수 있습니다. JSON 백업을 지원하지만 서버 복구 기능은 없습니다.

## 선택 결과 전달

- 선택지에서 기본 수치와 주요 확률 분기를 안내하지만, 치료·법률·연속 사건 전체의 모든 결과를 정확한 수치로 미리 보여주지는 않습니다.
- 자동 시간 진행의 변화와 선택 효과를 더 명확히 구분하는 결과 요약 알림을 검토할 수 있습니다.
- 상태 한도에 의해 잘리는 변화와 실제 적용량을 더 쉽게 비교하는 개선이 가능합니다.

## 콘텐츠와 밸런스

- 5,964개는 파생·후속 항목을 포함한 데이터 수입니다. 같은 구조가 반복되는 체감을 줄이는 독립 사건 확대가 필요합니다.
- 테스트 통과가 완성된 경제 밸런스나 모든 장기 선택 조합의 검증을 뜻하지 않습니다.
- 나이·종족·가족 조건에 맞는 표현과 장기 선택 결과를 계속 점검할 필요가 있습니다.

## 화면과 접근성

- 실제 모바일 기기 및 Safari 검증
- 최신 연간 게이지·긴 효과 안내가 있는 선택 팝업의 작은 화면 재검증
- 키보드·스크린리더와 긴 선택지 탐색 개선

## 저장소 후속 작업

- 현재 저장소는 문서만 포함합니다. 게임 원본 소스와 이미지 자산의 업로드는 후속 작업입니다.
- 소스 공개 시 불필요한 빌드 파일·로컬 저장·인증 정보·개인 경로를 제외해야 합니다.
- 코드·이미지의 이용 허락 범위를 결정하기 전에는 임의의 오픈소스 라이선스를 선언하지 않습니다. 공개 열람과 재사용 허가는 구분합니다.
