# 개발 과정과 주요 변경 사항

## 1. 기반 게임과 콘텐츠 확장

출생부터 사망까지의 시간·활동·사건·상태·저장을 구성하고 가족, 건강, 법률, 교육, 직업, 경제 기능을 연결했습니다. 이후 생활 사건과 장기 연쇄를 확장하고 건강·스트레스·보호자 가계의 밸런스를 보강했습니다.

## 2. 종족과 아이콘 개편

사용자 요청에 따라 어류와 모든 무척추동물을 제외하고 포유류·조류·파충류·양서류 범위로 정리했습니다. 제외된 32종 대신 새 포유류를 추가해 총 132개 프로필을 유지했습니다. 각 종족에 개별 아이콘을 연결하고 이전 저장의 제외 종족과 관련 사건을 새 구성으로 이전하도록 했습니다.

## 3. 공개 사이트와 시작 화면

공개 웹사이트를 배포한 후, 첫 접속에서 바로 게임 화면이 나타나던 흐름을 소개 화면과 시작하기/이어하기로 정리했습니다. 수인 사회에서 살아가는 게임이라는 주제가 드러나도록 ‘동물이 살아가는 도시’ 표현을 ‘132종의 수인이 함께 살아가는 현대 사회’로 수정했습니다.

## 4. 상단 시간 영역과 선택 팝업

시간 보내기를 화면 상단에 고정하고 선택지를 모달 팝업으로 변경했습니다. 팝업 닫기·재열기, 키보드 포커스 관리, 모바일 정보 탭을 연결했습니다. 이후 선택창에서도 캐릭터 아이콘·이름·종족·나이·현금을 볼 수 있게 보완했습니다.

## 5. 영유아 경제와 종족 사회생활

0세부터 현금 50만원을 갖던 비현실적인 시작 조건을 개인 현금 0원으로 조정했습니다. 보호자 자산, 미성년 용돈, 개인 지출, 보호자 관리 저축, 성인 인계를 구분했습니다.

현대 사회의 학교·직장·주거·교류 상황에서 종족 특성을 고려한 선택과 후속 결과를 추가했습니다. 데이터 파생 항목 수와 독립 이야기 수를 구분해 기록했습니다.

## 6. 기능 연결과 사용자 흐름 점검

저장 전환 중 중복 입력과 상태 덮어쓰기, 파산 때 관리 저축 잔액이 남는 문제, 네 가지 선택을 두 가지로만 보여주던 입력 예시를 수정했습니다. 새 게임·시간 진행·사건·저장 복원·내보내기/가져오기·이전 인생 보관을 실제 브라우저로 점검했습니다.

## 7. 연간 게이지와 자동 진행

진행 일수와 퍼센트를 보여주는 게이지를 추가한 뒤, 사용자 요청으로 1일/1주/1개월/1년 버튼을 제거했습니다. 단일 버튼으로 1년 계획을 시작하고 사건에서 자동 정지, 선택 후 자동 재개하도록 변경했습니다. 일시정지와 저장 후 진행률 복원을 지원합니다.

## 8. 선택 결과의 투명성

상태 게이지가 임의로 움직이는지 알기 어렵다는 피드백에 따라 선택지 자체에 수치 변화를 표시했습니다. 기본 효과와 확률 효과, 즉시/완료 적용 시점을 구분했습니다. 질병·법률·연속 사건처럼 결과가 고정되지 않은 항목은 조건부 안내를 제공합니다.

## 버전 표기

코드의 패키지 버전은 0.8.0입니다. 공개 호스팅의 저장·배포 버전은 별도로 증가했으며 마지막 확인 배포는 11번입니다. 이 문서 저장소 생성 자체는 게임의 새 배포나 기능 변경을 뜻하지 않습니다.
